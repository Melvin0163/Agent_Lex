# Section 16. Inspectors to be public servants

Part of [Maternity Benefit Act, 1961](overview.md). Status: repealed, replaced by Code on Social Security, 2020.

## Text

Maternity Benefit Act,1961 
16. Inspectors to be public servants 
Every Inspector appointed under this Act shall be deemed to be a

public servant within the meaning of section 21 of the Indian Penal Code (45 of

1860).
